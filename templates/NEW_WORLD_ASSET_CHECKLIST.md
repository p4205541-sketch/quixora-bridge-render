# New-world asset checklist

## Blockout
- [ ] Ground/terrain dimensions and elevation
- [ ] Main structures and landmarks
- [ ] Camera path and camera-safe corridors
- [ ] Character action area and entrances/exits

## Architecture / interiors
- [ ] Wall thickness, corners, trim and facade breaks
- [ ] Recessed windows and doors with frames
- [ ] Roof silhouette, eaves, fascia and supports
- [ ] Interior floor/walls/ceiling depth where visible
- [ ] Stairs, railings, balconies and structural supports
- [ ] Signs, lamps, gutters, pipes and story-specific details

## Surfaces / materials
- [ ] Correct material scale and UV density
- [ ] Base colour/albedo variation
- [ ] Roughness response
- [ ] Normal/bump/height detail where useful
- [ ] No obvious texture stretching or repetitive tiling
- [ ] Wood grain / masonry seams / ground breakup visible at camera distance

## Environment dressing
- [ ] Foreground props
- [ ] Midground story props
- [ ] Background silhouettes and skyline
- [ ] Vegetation with varied shapes and heights
- [ ] Water/road/grass/dirt transitions
- [ ] All props have believable contact/support

## Cinematography
- [ ] Wide establishing frame
- [ ] Character/action frame
- [ ] Close-up/hero-prop frame if required
- [ ] Every transition inspected before and after boundary
- [ ] No geometry clipping or subject obstruction
- [ ] Focus follows the intended subject

## Final QA
- [ ] Characters preserve design and proportions
- [ ] Contact shadows and occlusion look natural
- [ ] Lighting matches location/time/weather
- [ ] Bloom/DOF/haze do not hide story information
- [ ] Preview stills visually inspected
- [ ] Render time and memory checked at target scale
